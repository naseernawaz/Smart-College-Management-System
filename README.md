Smart College Management System — GCT Bhakkar

📖 Project Description

Smart College Management System is a web-based platform designed to digitally manage the academic and administrative activities of Government College of Technology (GCT) Bhakkar. It provides a centralized system for managing students, teachers, technology programs, classes, subjects, attendance, results, timetables, notices, and fee records. The platform includes role-based dashboards for Admin, Teachers, and Students, along with a special Class Representative (CR) attendance feature that allows teachers to grant selected students permission to submit class attendance.

❗ Problem Statement

Many college activities are managed through manual registers and paperwork, making it difficult to maintain accurate student records, monitor attendance, manage examination results, and share important notices. Teachers and administration may spend unnecessary time managing academic information manually. Students also face difficulties accessing their attendance records, results, timetables, and fee information. This project aims to solve these problems through a centralized digital college management platform.

🎯 Objectives

To provide a centralized platform for managing college academic and administrative records.
To digitize student and teacher information.
To manage attendance and automatically calculate attendance percentages.
To manage examination marks, results, and grades.
To provide digital timetable and notice management.
To manage student fee records and payment status.
To implement role-based access for Admin, Teachers, and Students.
To allow teachers to assign Class Representatives (CRs) for attendance management.
To improve efficiency, accuracy, and accessibility of college information.

✨ Key Features

For Admin: Manage students, teachers, technology programs, classes, subjects, attendance, results, fees, notices, timetables, and reports.
For Teachers: View assigned classes and subjects, mark attendance, enter student marks, view academic records, and manage CR attendance permissions.
For Students: View personal profile, attendance percentage, results, grades, timetable, notices, and fee status.
For Class Representatives (CR): Receive attendance permission from a teacher, mark Present/Absent/Late for an authorized class and subject, and submit attendance for teacher verification.
Smart Features: Automatic attendance calculation, grade calculation, low-attendance warnings, fee balance calculation, dashboard statistics, and search/filter functionality.
Security: JWT authentication, password hashing, protected APIs, and role-based authorization.

🚀 Basic Setup Instructions

(Note: This project is developed in phases. Some features may still be under development.)
Clone the repository: git clone YOUR_GITHUB_REPOSITORY_URL
Open the project folder: cd smart-college-management-system
Install dependencies: npm install
Create a .env file in the project root and add your MONGODB_URI, JWT_SECRET, and PORT.
Start the backend: npm run dev
Open the frontend client/index.html using VS Code Live Server.
Open the application in your browser and test the available features.
